# Ansh Air Cool - Website Redesign (Preview)

Redesign preview for the [Ansh Air Cool](https://github.com/AKASH991833/anshaircool.com) business website. This repo holds the proposed new look for review before anything replaces the live site. **It is a preview, not the live site.**

## What is inside

- `index.html` - the redesigned single-page site
- `styles.css`, `site.js` - styling and interactions

No backend, no build step.

## Run locally

Serve the folder with any static file server and open the page:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
